# eng-radio

仁爱英语 同步练测评（九年级上册）听力播放器

---

这是一个基于 GitHub Pages / Cloudflare Pages部署的轻量级英语听力网页播放器。无需下载 App，直接通过浏览器即可流式播放音频。

## ✨ 功能特性

- **流式播放，不占内存**：使用 HTML5 Audio 流式传输 (`preload="metadata"`)，音频数据随播随取，不占用手机本地存储。
- **现代化 UI**：深色模式、卡片式设计、响应式布局，完美适配手机与电脑端。
- **无广告无弹窗**：纯净的界面，专注于听力练习。
- **互斥播放**：点击播放某个音频时，自动暂停其他音频，避免多声源重叠。
- **锁屏控制**：集成 Media Session API，支持在手机锁屏界面查看标题并控制播放/暂停。
- **自动分类**：将音频分为“正文部分 (Text)”与“试卷部分 (Test)”。

## 🚀 使用方法

1. 打开浏览器访问部署好的网址（例如：https://你的用户名.github.io/eng-radio/）。
2. 点击任意音频的播放按钮即可开始流式播放。
3. 建议：在手机浏览器中点击“添加到主屏幕”，即可获得类似 App 的体验。

## ⚠️ 注意事项

- 后台播放限制：受限于移动端浏览器的省电策略，锁屏或切后台后，部分系统（尤其是 iOS）可能会暂停播放。建议在锁屏界面点击“播放”按钮，或配合系统自带音乐播放器使用。
- 网络要求：GitHub Pages 在国内访问可能不稳定，如出现加载缓慢或卡顿，请检查网络环境。
- 音频版权：仓库中的听力音频仅供个人学习使用，请勿用于商业用途，版权归原出版社所有。
